============================================================
  兒童注意力監測與量化分析平台
  Multi-modal AI Joint Attention Assessment System

  免安裝版使用說明
============================================================


【一、你需要什麼】

  作業系統   Windows 10 / 11（64 位元）
  顯示卡     NVIDIA 顯卡，並安裝最新驅動程式
  硬碟空間   至少 20 GB 可用空間
  網路       不需要（模型都已內含）

  ⚠ 關於顯示卡：
  這套系統每一幀都要跑 YOLO 物件偵測與 ResNet-50 視線估計。
  沒有 NVIDIA 顯卡的話程式仍然可以開啟、可以看報表，但是按下
  「開始分析」會慢到不切實際（一支 6 分鐘的影片可能要跑數小時）。

  ⚠ 關於顯示記憶體：
  語音辨識用的是 Whisper large-v3，以 FP32 執行約需 8~10 GB
  顯示記憶體。顯示記憶體不足時系統會自動改用 CPU 做語音辨識，
  結果一樣正確，但那一段會慢很多（一支 6 分鐘的影片約 10~20 分鐘）。
  主控台會明白顯示「顯示記憶體不足，改用 CPU 重新辨識」。
  影像分析（YOLO / 視線）仍然使用 GPU，不受影響。
  同一支影片的語音辨識結果會存進快取，第二次不會再重跑。

  CUDA 函式庫已經包在裡面了，你不需要另外安裝 CUDA Toolkit，
  但顯示卡驅動程式必須是你電腦上已經有的。
  驅動可到 https://www.nvidia.com/download/index.aspx 更新。


【二、怎麼開始】

  1. 把整個壓縮檔解壓縮到一個路徑不含中文的資料夾
     建議：D:\attention  或  C:\attention

  2. 雙擊  START_UI.bat

  3. 第一次執行會自動做三件事，大約 5～15 分鐘：
       - 解壓縮內含的 Python 環境
       - 修正環境內的路徑設定
       - 安裝語音辨識與文字辨識的模型檔
     畫面上會有進度訊息，請耐心等候，不要關掉視窗。

  4. 之後每次啟動只要 10～20 秒。


【三、怎麼跑分析】

  1. 把要分析的影片（.mp4 / .avi / .mov / .mkv）放進：

         app\hurry\video\

  2. 雙擊 START_UI.bat 開啟介面

  3. 在「① 影片載入與設定」頁選擇影片，右下角按「開始分析」

  4. 自動跳到「② 即時監測」頁，可以看到 AI 逐幀的判斷過程

  5. 分析完成後自動跳到「③ 單次結果報表」

  結果會輸出到：

         app\hurry\output\
             {影片名}.mp4    帶標註的分析影片
             {影片名}.txt    完整分析報告

  ⚠ 第一次分析某支影片時，系統要先做語音辨識（Whisper），
    依影片長度可能需要數十秒到數分鐘。同一支影片再跑第二次
    會直接讀快取，跳過這一步。


【四、介面的四個頁面】

  ① 影片載入與設定
     選影片、調整分析參數（關卡範圍、跳幀、視線校正等）、
     查看 GPU 狀態、開始分析。

  ② 即時監測
     左邊是帶標註的畫面（物件框、視線箭頭、指向射線），
     右邊是即時判定燈與各關 T0 / TB / TH 表格，
     下方是進度條與主控台訊息。可隨時按「停止分析」，
     已分析的部分仍會寫出報告。

  ③ 單次結果報表
     四個分頁：總覽圖表、各關明細、語音逐字稿、事件流水。
     可匯出 CSV / Excel，也可播放分析影片。
     按「開啟報告檔…」可以載入任何一份既有的 .txt。

  ④ 歷史統計比較
     掃描輸出資料夾內所有報告做跨受試者比較。
     可在表格中標記 ASD / TD 分組，下方圖表會即時更新
     兩組各關的平均得分。可匯出總表 Excel。


【五、這套系統在評估什麼】

  施測流程共 14 個關卡，兒童在每一關被引導去注意某個目標。
  系統從錄影中自動抓出三個關鍵時間點：

    T0  指示時間 —— 系統聽到關鍵字或偵測到目標物出現的瞬間
    TB  看向物品 —— T0 之後，兒童首次注視目標物的瞬間
    TH  看回施測者 —— TB 之後，兒童把視線移回施測者的瞬間

  三者加上「是否有指向動作」換算成每一關的反應等級：

    HI  指向 ＋ 看回人           高度主動分享
    LI  看向物 ＋ 看回人（無指向） 視線交替主動
    HR  遠物關卡，僅達成一項      有基本反應但未主動
    LR  其他關卡，僅達成一項      低反應
    F   皆未達成                 無反應

  更完整的說明在 app\README.md。


【六、遇到問題】

  ● 視窗閃一下就消失
    通常是解壓縮不完整。請確認 START_UI.bat、env.tar.gz、
    app 資料夾都在同一層，然後重新解壓縮一次。

  ● 提示 tar 不是內部或外部命令
    你的 Windows 版本太舊，沒有內建 tar。請安裝 7-Zip，
    手動把 env.tar.gz 解壓縮成一個名為 env 的資料夾
    （與 START_UI.bat 同一層），再重新執行 START_UI.bat。

  ● 介面開得起來，但分析非常慢
    多半是沒有偵測到 GPU。在「① 影片載入與設定」頁左上角
    的「推論裝置」磚會顯示 GPU 或 CPU。顯示 CPU 的話請
    更新 NVIDIA 驅動程式。

  ● 分析中途出錯
    切到「② 即時監測」頁下方的主控台，錯誤訊息都在那裡。

  ● 想從命令列跑批次分析
    開啟命令提示字元，切到這個資料夾，執行：
        env\Scripts\activate.bat
        cd app\hurry
        python main.py
    這會自動掃描 app\hurry\video\ 內所有影片，全部跑完為止。


【七、資料說明】

  這個發佈版本不含任何受試者影片或分析結果。
  video 與 output 資料夾是空的，供你放置自己的測試影片。

  請注意，分析報告（.txt）會包含語音辨識的完整逐字稿。
  若處理的是臨床錄影，散布這些檔案前請確認符合你所屬單位
  的研究倫理規範。
