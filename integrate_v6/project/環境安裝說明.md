# 環境安裝說明

本文件說明如何在新電腦上重建「兒童注意力監測系統」所需的 Python 執行環境。

---

## 前置需求

| 項目 | 版本 / 說明 |
|------|------------|
| 作業系統 | Windows 10 / 11 |
| NVIDIA 顯卡驅動 | 支援 CUDA 11.8（驅動版本 ≥ 452.39）|
| Anaconda / Miniconda | 任意新版，用來建立虛擬環境 |
| Python | **3.9**（由 conda 管理，不需另裝）|

---

## 安裝步驟

### Step 1：建立 conda 虛擬環境

```powershell
conda create -n attention_integrate python=3.9 -y
conda activate attention_integrate
```

### Step 2：安裝 PyTorch（CUDA 11.8 版）

> ⚠️ 一定要用這行，不能用 `pip install torch`（那會裝到 CPU 版）

```powershell
pip install torch==2.7.1+cu118 torchaudio==2.7.1+cu118 torchvision==0.22.1+cu118 --index-url https://download.pytorch.org/whl/cu118
```

### Step 3：安裝其餘套件

```powershell
pip install -r requirements.in
```

> `requirements.in` 在專案根目錄（`C:\project\requirements.in`）。

### Step 4：確認 opencv 只裝一個版本

```powershell
pip uninstall opencv-python -y
```

> `opencv-contrib-python`（含 TrackerKCF）已在 Step 3 裝好，不需要 `opencv-python`，兩者共存會互蓋。

---

## 驗證安裝

全部裝完後，執行：

```powershell
python -c "import cv2, easyocr, ultralytics, mediapipe, whisper, torch; print('CUDA:', torch.cuda.is_available())"
```

預期輸出：
```
CUDA: True
```

若顯示 `CUDA: False`，代表 PyTorch 的 CUDA 版本沒裝對，回到 Step 2 重裝。

---

## 快速重建（使用匯出的 yml）

若有 `environment_export.yml`（執行 `conda env export --no-builds` 產生），可直接：

```powershell
conda env create -f environment_export.yml
conda activate attention_integrate

# yml 不含 PyTorch 的 index-url，需手動補裝：
pip install torch==2.7.1+cu118 torchaudio==2.7.1+cu118 torchvision==0.22.1+cu118 --index-url https://download.pytorch.org/whl/cu118
```

---

## 常見問題

| 問題 | 原因 | 解法 |
|------|------|------|
| `ModuleNotFoundError: No module named 'cv2'` | opencv 沒裝 | `pip install opencv-contrib-python==4.13.0.92` |
| `AttributeError: module 'cv2' has no attribute 'TrackerKCF'` | 裝了 opencv-python 而非 contrib 版 | `pip uninstall opencv-python -y` |
| `CUDA: False` | PyTorch 裝到 CPU 版 | 重跑 Step 2 |
| `pip-compile` 找不到 | pip-tools 未裝 | `pip install pip-tools` |
| Whisper 找不到模型 | 首次執行會自動下載（需網路） | 等待下載完成即可 |

## 執行程式

```powershell
conda activate attention_integrate

# 批次版（掃描 hurry/video/ 底下所有影片）
cd C:\project\hurry
python main.py

# 完整版（互動式，手動選影片與 ROI）
cd C:\project
python main.py

# 統計分析（將 event_record txt 放到 summarize/files/）
cd C:\project\summarize
python summarize.py
```
