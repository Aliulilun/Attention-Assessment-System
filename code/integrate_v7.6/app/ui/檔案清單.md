## 一、新增的檔案（全部在 `ui/`）

### 進入點與基礎建設

| 檔案 | 負責什麼 |
|------|----------|
| `app.py` | 主視窗。側邊四個頁籤、頁面之間的訊號串接、**批次佇列**（依序跑完、單支失敗不中斷整批、停止鍵中止整批、結束彙總）、關閉時的收尾（等分析寫完報告、釋放 VRAM）。**執行的就是這一支。** |
| `run_ui.bat` | 啟動器（ui\ 版）。切到專案根目錄 → 啟動 conda 環境 → 執行 `app.py`。 |
| `qt_compat.py` | PySide6 / PyQt5 相容層。全專案唯一碰到「兩種 Qt 綁定 API 不一樣」的地方，其他檔案只從這裡 import。裝哪一個都能跑。 |
| `theme.py` | 深色主題樣式表（QSS）與色票。顏色與分析影片上的 OpenCV 標註同色系：綠＝命中、黃＝GAZING、橘＝機器人、紅＝未達成。 |

### 與分析管線的橋接

| 檔案 | 負責什麼 |
|------|----------|
| `pipeline_api.py` | 用 `importlib` 把 `hurry/main.py` 當函式庫載入（不能直接 `import main`，會跟根目錄的 `main.py` 撞名）。另外負責影片清單、輸出路徑推算、config 讀寫、GPU 狀態查詢，以及**模型快取**——設定沒變就不重載 YOLO/Gaze/EasyOCR，省掉每次 30 秒以上的冷啟動。 |
| `workers.py` | `AnalysisWorker`（QThread）。整條管線跑在背景執行緒，避免視窗卡成「沒有回應」。三件事：把 `print()` 轉接到介面主控台、把畫面節流後送給 GUI、提供中止旗標。另含 `bgr_to_qimage()` 影格轉檔。 |

### 資料與顯示元件

| 檔案 | 負責什麼 |
|------|----------|
| `report_parser.py` | 把 `event_record` txt 解析成結構化資料（各關 T0/TB/TH/等級、Gazing 統計、Whisper 逐字稿、事件流水）。報表頁與歷史頁共用。 |
| `widgets.py` | 共用元件：卡片、數值磚、狀態指示燈，以及四種自繪圖表（長條圖、分組長條圖、圓環圖、階段時間軸）。圖表用 QPainter 自繪而非 matplotlib——避免中文變方塊、也避免綁定版本相依。 |

### 四個頁面（`ui/pages/`）

| 檔案 | 對應頁籤 | 負責什麼 |
|------|----------|----------|
| `setup_page.py` | ① 影片載入與設定 | 影片清單（勾選框可多選、標記哪些已有結果、全選／只選未分析）、輸出目錄、分析參數（關卡範圍、三種跳幀、視線裝置與 Pitch 校正、氣球彩度門檻）、GPU 狀態、開始分析。`start_requested` 傳的是**影片清單**，單支就是長度 1。 |
| `monitor_page.py` | ② 即時監測 | 標註畫面、五盞即時判定燈、各關 T0/TB/TH 即時表格、階段時間軸、進度條、主控台。批次時標題顯示「第 N / M 支」，主控台跨影片保留不清空。 |
| `report_page.py` | ③ 單次結果報表 | 摘要磚、各關得分長條圖、反應等級圓環、各關注視次數、各關明細表、語音逐字稿、事件流水（可篩選）、匯出 CSV/Excel、播放分析影片。 |
| `history_page.py` | ④ 歷史統計比較 | 掃描輸出資料夾所有報告、跨受試者總表、ASD/TD 分組標記、組間各關平均得分比較圖、匯出總表 Excel。 |

## 三、修改到的既有檔案

只動了兩支，而且都是**向下相容**——命令列 `python hurry/main.py` 的行為與改動前完全一樣。

### `hurry/main.py`

**1. `process_single_video()` 新增兩個選用參數**

```python
def process_single_video(..., frame_callback=None, should_stop=None):
```

- `frame_callback(payload)`：每幀把已標註的畫面與即時統計（階段、觸發窗、指向、視線、分數、各關紀錄）丟給介面。
- `should_stop()`：每幀開頭檢查一次，回傳 True 就中止；中止後仍會走 `finally`，照樣寫出報告、縫合音軌。

兩者預設 `None`，不傳就整段跳過，等於改動前。

**2. 把原本寫死在 `main()` 裡的初始化抽成可重用函式**

| 函式 | 原本位置 |
|------|----------|
| `load_project_config()` | main() 內讀 config.yaml 那段 |
| `enable_cuda_optimizations()` | main() 內印 GPU 狀態 + 開 cudnn.benchmark/TF32 那段 |
| `prepare_speech_cache()` | main() 內 Step 0 的 Whisper 迴圈本體 |
| `build_shared_components()` | main() 內 Step 1 載入 ModelManager / InteractionEngine / GazePipeline / EasyOCR 那段 |

`main()` 改成呼叫這幾支，介面也呼叫同樣這幾支。**單一事實來源**——不會出現「介面跑出來的分數跟命令列不一樣」。

### `.gitignore`

加一行 `ui/groups.json`（本機分組標記，不進版控）。
