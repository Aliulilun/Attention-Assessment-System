============================================================
  注意力分析結果檢視器
  Joint Attention Report Viewer

  使用說明（macOS / Windows / Linux）
============================================================


【這是什麼】

  用來閱讀「兒童注意力監測與量化分析平台」產出的分析報告。
  可以看各關得分圖表、反應等級分布、逐字稿、事件流水，
  也可以做跨受試者的 ASD / TD 分組比較與匯出 Excel。

  ⚠ 這個版本「不含」AI 分析功能。
  要自己放影片跑分析，需要 Windows + NVIDIA 顯卡的完整版。

  好處是：不需要顯示卡、不需要下載任何模型、體積很小，
  Mac 和一般筆電都能用。


【需要什麼】

  Python 3.9 以上（macOS 通常已內建，可在終端機輸入
  python3 --version 確認）
  第一次執行需要網路，用來安裝介面套件（約 100 MB）


【macOS 怎麼開】

  ⚠ 從網路下載的檔案，macOS 預設會擋下來，請照下面的方式做。

  方式一（推薦，最不會出錯）：

    1. 打開「終端機」（Terminal）
       - 按 Command + 空白鍵，輸入「終端機」按 Enter

    2. 輸入 bash 後空一格，然後把 START_VIEWER.command
       這個檔案「拖曳」到終端機視窗裡，路徑會自動填好

       看起來像這樣：
         bash /Users/你的名字/Downloads/viewer/START_VIEWER.command

    3. 按 Enter

  方式二（雙擊）：

    1. 先在終端機執行一次（把資料夾拖進去取代 <資料夾>）：
         chmod +x <資料夾>/START_VIEWER.command

    2. 對 START_VIEWER.command 按住 Control 再點一下，選「打開」
       （直接雙擊會被 Gatekeeper 擋掉，一定要用 Control + 點選）

    3. 跳出警告時選「打開」

  第一次執行會建立虛擬環境並安裝套件，約 1~3 分鐘，
  終端機會顯示進度。之後每次啟動只要幾秒。


【Windows 怎麼開】

  雙擊 START_VIEWER.bat 即可。

  若跳出「Windows 已保護您的電腦」，點「其他資訊」→「仍要執行」。
  更好的做法是解壓縮「之前」先對 ZIP 按右鍵 →「內容」→
  勾選「解除封鎖」→ 確定。


【怎麼用】

  左側兩個頁籤：

  ① 單次結果報表
     按右上角「開啟報告檔…」載入任何一份 .txt 分析報告。
     四個分頁：
       總覽     — 各關得分長條圖、反應等級圓環、各關注視次數
       各關明細 — T0 / 計分結束 / 指向 / TB / TH / 次數 / 總分 / 等級
       語音逐字稿 — Whisper 辨識結果，命中關鍵字的段落標綠色，
                    那就是 T0 的判定依據
       事件流水 — 完整事件 log，可用關鍵字篩選
     右上角可匯出 CSV / Excel。

  ② 歷史統計比較
     按「更換資料夾…」選一個放了多份 .txt 的資料夾，
     會列出所有受試者的結果。
     在「分組」欄選 ASD 或 TD，下方圖表會即時更新兩組
     各關的平均得分。雙擊任一列可開啟那位的單次報表。
     右上角可匯出總表 Excel。

  分組設定會記在 app/ui/groups.json，下次開啟自動帶入。


【報告在哪裡】

  分析報告是 .txt 檔，檔名通常是影片編號（例如 42.txt）。
  由完整版分析後產生在 hurry/output/ 資料夾。
  把這些 .txt 放進任何一個資料夾，用「更換資料夾…」指過去即可。


【評估指標說明】

  T0  指示時間 —— 系統聽到關鍵字或偵測到目標物出現的瞬間
  TB  看向物品 —— T0 之後，兒童首次注視目標物的瞬間
  TH  看回施測者 —— TB 之後，兒童把視線移回施測者的瞬間

  反應等級（TB 1 分 ＋ TH 2 分 ＋ 指向 1 分，共 0~4 分）：

    HI  指向 ＋ 看回人             高度主動分享
    LI  看向物 ＋ 看回人（無指向）  視線交替主動
    HR  遠物關卡，僅達成一項        有基本反應但未主動
    LR  其他關卡，僅達成一項        低反應
    F   皆未達成                   無反應


【遇到問題】

  ● macOS 說「無法打開，因為無法驗證開發者」
    用上面的「方式一」從終端機執行，或用 Control + 點選 →「打開」。

  ● 終端機說 command not found: python3
    請先安裝 Python：https://www.python.org/downloads/

  ● 套件安裝失敗
    多半是網路問題。刪掉資料夾裡的 .venv 再執行一次。

  ● 畫面中文變成方框
    極少見。若發生請告知，這表示系統缺少中文字型。

  ● 想要能自己跑分析的完整版
    需要 Windows 10/11 + NVIDIA 顯卡（建議 8GB 以上顯示記憶體）。
    請向提供這份檔案的人索取完整版安裝包。
