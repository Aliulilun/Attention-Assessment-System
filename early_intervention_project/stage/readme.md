#  EasyOCR 即時數字牌辨識與階段追蹤系統 (Sign Number Recognition)

這是一個基於 **OpenCV** 與 **EasyOCR** 的 Python 電腦視覺腳本。主要功能是從影片中動態追蹤並辨識特定的數字牌（1~8），並根據讀取到的數字，自動、穩定地推進系統的「當前階段（Current Stage）」。

本程式特別針對「運算效能」與「辨識穩定度」進行了優化，非常適合用於需要辨識實體數字卡牌來觸發流程的互動系統或專題展示。

##  核心功能與特色

* **自訂搜索結界 (ROI Selection)**：程式啟動時允許使用者手動框選牌子可能出現的大範圍區域（例如桌面）。這能大幅過濾背景雜訊，並極大化 OCR 的運算效率。
* **效能最佳化 (Frame Skipping)**：採用每 15 幀（約 0.5 秒）執行一次 OCR 的設計，確保影片播放與視覺反饋保持流暢，不會因為每一幀都做 OCR 而卡頓。
* **微小字體強化辨識**：自動將擷取的畫面轉為灰階，並強制放大 2.5 倍（`mag_ratio=2.5`），專治極細字體（如數字 7）或連在一起的數字（如 76）。
* **穩定與防呆機制**：
* **單向階段推進**：確保階段只能往前進，且設有「最多跳 2 級」的限制，防止因誤判而導致階段暴衝。
* **視覺防閃爍 (Anti-Flicker)**：具備記憶上一秒最佳辨識結果的功能，讓綠色鎖定框在沒有執行掃描的幀數中依然穩定顯示。
* **自動建立目錄**：自動檢查並建立 `output` 資料夾，避免輸出影片時發生路徑崩潰錯誤。



## 環境與依賴套件

請確保你的環境中已安裝 Python 3.x，並安裝以下必備套件：

```bash
pip install opencv-python easyocr

```

*(備註：首次執行 EasyOCR 時，系統會自動下載所需語言模型，可能需要稍微等待。)*

##  專案檔案架構

在執行程式前，請確保你的資料夾結構如下：

```text
專案根目錄/
├──  main.py               # 你的辨識主程式碼
├──  video/                
│   └──  .mp4            # 欲辨識的輸入影片 (請確認檔名與程式碼一致)
└──  output/               # 程式執行後會自動產生此資料夾與輸出影片

```

##  使用說明

1. **準備影片**：將測試影片放置於 `video/` 目錄下，並命名為 `10.mp4`（或自行進入程式碼修改 `VIDEO_PATH`）。
2. **執行程式**：
```bash
python main.py

```


3. **框選辨識區域 (ROI)**：
* 程式啟動後會彈出畫面。
* 請按住 **滑鼠左鍵** 拖曳出一個包含「牌子可能出現區域」的黃色大框框。
* 選定後，按下 **`Enter`** 或 **`Space` (空白鍵)** 確認。


4. **開始辨識**：
* 系統將自動進入即時辨識模式。
* 畫面上方會顯示當前系統認定的階段 (`Current Stage: X`)。
* 成功捕捉到牌子時，會用綠色框將其標記並顯示信心指數。


5. **安全退出**：
* 隨時可以在辨識視窗中按下 **`Esc`** 鍵，或是於終端機按下 **`Ctrl + C`** 安全結束程式。
* 系統會自動將辨識過程的影片儲存到 `output/output_ocr_window1.mp4` 中。



##  階段推進邏輯說明

為了避免雜訊干擾，系統內建了嚴謹的邏輯過濾：

1. **白名單過濾**：只讀取 `12345678` 這些數字。
2. **連體數字拆解**：如果畫面上同時掃到多張牌子（或連在一起如 76），程式會將其拆解，並取出裡面的最大值。
3. **推進條件**：假設現在是階段 1，若畫面掃到 2 或 3（`current_stage <= max_num <= current_stage + 2`），則允許推進。若是掃到 9 或其他誇張數字，系統會將其視為雜訊並忽略。
